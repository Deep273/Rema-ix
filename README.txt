LandScope — запуск на Windows

Локальный запуск

1. Распакуй весь ZIP в одну папку. Запусти start.cmd.
2. Введи пароль от PostgreSQL, который у тебя уже есть. При вводе пароль скрыт.
   Для просмотра вёрстки без подключения к базе просто нажми Enter.
3. Откроется http://localhost/ (порт 80). Оставь окно сервера открытым.
4. Правь файлы в wwwroot и обновляй страницу. После правок server.cjs перезапусти start.cmd.

Каталог: http://localhost/
Подбор коммерческих аналогов: http://localhost/?section=commercial&view=analogs
Отчёт о продажах коммерческих объектов: http://localhost/?section=commercial&view=market
Подбор земельных аналогов: http://localhost/report/analogs/
Каталог земельных участков: http://localhost/land.html

Если порт 80 занят, задай REALTY_PORT в PowerShell перед запуском.
Скрипт откроет браузер по адресу с выбранным портом.

По умолчанию сайт читает land_plots_db под пользователем postgres. На сервере
с адресом 192.168.0.10 приложение подключается к базе по 192.168.0.10:5432.
На остальных компьютерах используется публичный адрес 90.188.118.197:5432.
Адрес подключения отображается в окне запуска. При необходимости задайте
PGHOST, PGPORT, PGDATABASE и PGUSER перед запуском.
Пароль нужен серверу только на время запуска и не входит в архив.
Подключение открывается в режиме чтения. Сайт показывает то, что парсер
уже записал в базу; отдельно запускать или настраивать парсер он не пытается.
Скриншоты Ru09 в окне объявления загружаются из соседней папки Parser\media.
Если архив хранится в другом месте, задайте REALTY_MEDIA_DIR до запуска.
В базе сейчас в основном коммерческие объявления. Пустая выдача при выбранном
сегменте, сделке или фильтре означает, что подходящих записей в базе нет.
Участки показываются в сотках, остальные объекты — в квадратных метрах.
Для аренды интерфейс показывает месячную цену. Явно годовая цена делится на 12.
Если период аренды отсутствует в БД, сумма отображается как месячная.

Публичный запуск по HTTP

На сервере с внутренним IP 192.168.0.10 запусти обычный start.cmd.
Каталог откроется по http://localhost/ и будет доступен снаружи по
http://90.188.118.197/, если порт 80 проброшен на сервер и открыт в брандмауэре.
Если внутренний IP сервера изменился, задай новый адрес в REALTY_HOST перед
запуском и обнови проброс порта на роутере.

Публичный запуск с HTTPS

1. На Windows-сервере используйте Caddy 2.11.1 или новее. Исполняемый файл
   caddy_windows_amd64.exe или caddy.exe можно положить рядом со start-caddy.cmd.
   Скрипт также найдёт caddy.exe в PATH.
   Откройте входящие TCP-порты 80 и 443 в брандмауэре Windows.
   Если сервер за роутером, направьте оба порта на Windows-сервер.
2. Остановите старый экземпляр LandScope, который занимал порт 80.
   Запустите start-landscope-https.cmd двойным кликом или из PowerShell:

     .\start-landscope-https.cmd

   Введите пароль PostgreSQL и дождитесь адреса http://localhost:5011/
   в окне LandScope. По этому адресу можно проверить приложение на самом сервере.
3. Запустите start-caddy.cmd двойным кликом или из отдельного окна PowerShell:

     .\start-caddy.cmd

   Конфигурация использует публичный IP 90.188.118.197. Caddy получает
   и обновляет сертификат Let's Encrypt для IP и перенаправляет HTTP на HTTPS.
   Оставьте оба процесса запущенными для работы сайта и обновления сертификата.
4. Проверьте https://90.188.118.197/ из внешней сети. Адрес
   http://90.188.118.197/ должен перенаправлять на HTTPS.

Если Caddy возвращает 502 и пишет, что 127.0.0.1:5011 отклонил соединение,
запустите start-landscope-https.cmd и проверьте сообщение в окне LandScope.

Если публичный IP изменится или появится домен, задайте REALTY_PUBLIC_HOST
в окне Caddy до запуска. Для домена направьте DNS-запись на сервер.
Если задан REALTY_PORT, укажите одно и то же значение в обоих окнах.
В режиме -BehindCaddy приложение принимает запросы на 127.0.0.1.
